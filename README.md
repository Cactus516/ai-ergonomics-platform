# AI Ergonomics Platform

An AI-powered desktop application that helps users improve posture and workspace ergonomics using computer vision and real-time feedback.

## Project Goal

The goal of this project is to build an extensible ergonomics platform rather than a simple posture detector.

The platform will use computer vision to analyze posture, evaluate ergonomic setups, provide personalized coaching, and track long-term health habits.

This project is being developed as a long-term software engineering portfolio for university applications.

## Planned Features

- Live posture detection
- Slouch detection
- Ergonomic workspace assessment
- Personalized posture coaching
- Health analytics dashboard
- Focus and break reminders
- Gaming mode
- Progress tracking
